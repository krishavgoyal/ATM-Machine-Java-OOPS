# ATM-Machine-Java-OOPS
A console-based Java application that simulates real-world ATM functionalities like PIN verification, balance inquiry, deposits, and withdrawals using OOP principles.

*Features*
Security: PIN-based authentication to access account features.
Balance Inquiry: Real-time checking of the current account balance.
Cash Withdrawal: Securely deduct funds with built-in balance verification to prevent overdrafts.
Cash Deposit: Instantly update account balance with new deposits.
User-Friendly Menu: An interactive command-line interface for seamless navigation.

*Concepts Demonstrated*
Classes and Objects: Utilization of a main driver class (ATM_Machine) and a logic class (ATM).
Encapsulation: Managing state (Balance) and behavior (Methods) within a single class structure.
Scanner Class: Handling and validating various types of user input (int, float).
Conditional Logic: Implementation of if-else chains for transaction processing and PIN validation.
Recursion: Methods calling themselves to maintain the application flow.
